# 再久一点（P068）

一个**完全离线**的 Android 时长进阶应用：设目标 → 倒计时 → 结束确认 → 历史与统计 → 备份恢复。

- 不联网、不登录、不上传：Manifest 没有网络权限，训练记录只存在你的手机里。
- 三个页面：**训练 / 历史 / 设置**。
- 目标按项目记忆；历史记录保留当次目标快照。
- 统计：实际时长趋势、每周频率与平均时长、每周次数与表现关系（附分组分母）。
- 备份：完整 JSON（项目/目标/预设/历史/备注/设置）与 CSV（Excel 可直接打开）。
- 字体大小：设置 → 外观 → 字体大小，可选小 / 标准 / 大 / 特大，默认「标准（115%）」，立即生效并记住。
- 深色模式：设置 → 外观。
- 语音与反馈：点「开始训练」会震动并播报“开始训练”；每训练满 3 分钟播报一次（如 15 分钟目标会在 3/6/9/12 分钟提醒）；达到目标时播报并可继续。语音在应用处于前台时播放，设置 → 训练偏好 → 语音提醒 可单独关闭。

## 安装

APK：`dist/P068-zai-jiu-yi-dian-v1.0.0-debug.apk`

- 包名：`com.wanghoufan.zaijiuyidian`
- 版本：1.0.0（versionCode 1）
- 大小：15,670,066 字节
- SHA-256：`15cc5d3e133e256b7c0dcff38d55e0644e9e524e3ea74649ca0d17f93e9f6e5c`
- 这是 **DEBUG 测试签名**包，用于个人侧载体验，不是商店正式版。

手机上安装：把 APK 传到手机 → 用文件管理器点开 → 允许安装未知来源应用 → 安装。
或用数据线：

```bash
adb install -r -t dist/P068-zai-jiu-yi-dian-v1.0.0-debug.apk
```

小米 / Redmi（HyperOS）提示 `INSTALL_FAILED_USER_RESTRICTED` 时：设置 → 更多设置 → 开发者选项 → 打开「USB 安装」，并保持屏幕亮着再装。该开关在锁屏或重启后可能自动关闭。

## 使用

1. **训练**：选择项目 → 选目标档位或「自定义时间」→ 开始。
2. 到目标不会自动结束，可以继续；点「结束训练」后选择「计入历史」或「不计入」。
3. **历史**：看统计/图表，补录、编辑、删除、撤销；「最近删除」里可恢复。
4. **设置**：项目管理、预设档位、提示音/震动/语音提醒（仅应用在前台时）、外观、字体大小、备份导入导出。

## 数据与备份

- 卸载应用会删除本机数据；**卸载前先到设置 → 导出完整备份**。
- 导入：设置 → 导入与恢复 → 选择 JSON → 预览冲突 → 合并或覆盖。覆盖前会先在本机私有目录留一份安全副本，并在一个事务里替换。
- 备份含删除标记，合并旧备份不会让已删除记录复活；相同 UUID 以现有版本为准。

## 构建与测试

需要 JDK 17、Android SDK 36：

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

## 已知限制

- 锁屏/后台**不会响铃**；返回时显示真实经过时长。锁屏准点提醒未实现。
- 自动本地备份未实现；手动 JSON/CSV 可用。
- 功能验收在 Redmi Note 12 Pro（Android 14）完成；另在 Redmi Note 12T Pro（Android 15）与 Redmi Note 11 5G（Android 11）完成安装启动验证。
