# 再久一点（P068）

一个**完全离线**的 Android 双模式训练应用：时长倒计时 + 按组计次，共用完整历史与备份。

- 不联网、不登录、不上传：Manifest 没有网络权限，训练记录只存在你的手机里。
- 四个页面：**时长 / 次数 / 历史 / 设置**。
- 时长：真实倒计时、暂停/继续、超时继续、结束确认、目标快照、锁屏语音。
- 次数：按组记录实际次数，支持修改/撤销/超计划追加/提前结束/草稿恢复。
- 目标按项目记忆；时长与计次项目互不混用，历史记录保留当次计划与目标快照。
- 统计：成绩趋势、每周频率、频率关系三图；时长看分钟，计次看总次数/最佳单组，全部项目只合并训练次数与天数。
- 备份：完整 JSON V3（项目模式、计次计划、每组明细、草稿、设置）与 CSV；V1/V2 旧备份仍可读。
- 自动本地备份：设置 → 备份与恢复 → 选择文件夹（建议 Documents 下独立文件夹），数据变动后自动生成可校验快照，保留最近 7 个；可预览、恢复，恢复前自动写保护点。
- 字体大小：设置 → 外观 → 字体大小，可选小 / 标准 / 大 / 特大，默认「标准（115%）」，立即生效并记住。
- 深色模式：设置 → 外观。
- 语音与反馈：点「开始训练」会震动并播报“开始训练”；每训练满 3 分钟播报一次（如 15 分钟目标会在 3/6/9/12 分钟提醒）；达到目标时播报并可继续。开始训练后会启动前台服务，锁屏/切后台也继续播报（系统允许时）；通知权限被拒绝或系统强制停止时不保证。设置 → 训练偏好 → 语音提醒 可单独关闭。

## 安装

APK：`dist/P068-zai-jiu-yi-dian-v1.1.0-debug.apk`

- 包名：`com.wanghoufan.zaijiuyidian`
- 版本：1.1.0（versionCode 3）
- 大小：16,033,544 字节
- SHA-256：`3d81a707df8473a1e54365c7a815cc4ff359602c0a1812bc5e78a481d1055919`
- 这是 **DEBUG 测试签名**包，用于个人侧载体验，不是商店正式版。

手机上安装：把 APK 传到手机 → 用文件管理器点开 → 允许安装未知来源应用 → 安装。
或用数据线（`-r` 会保留旧数据并执行 Room v1→v2 原地迁移）：

```bash
adb install -r -t dist/P068-zai-jiu-yi-dian-v1.1.0-debug.apk
```

小米 / Redmi（HyperOS）提示 `INSTALL_FAILED_USER_RESTRICTED` 时：设置 → 更多设置 → 开发者选项 → 打开「USB 安装」，并保持屏幕亮着再装。该开关在锁屏或重启后可能自动关闭。

## 使用

1. **时长**：选择计时项目 → 选目标档位或「自定义时间」→ 开始；暂停/继续/结束并保存。
2. **次数**：选择计次项目 → 开始 → 逐组填实际次数 → 完成一组；可修改/撤销/追加，提前结束会弹出真实摘要。
3. **历史**：三类图表切换、项目/时间/搜索筛选；补录、编辑（计次可逐组改）、删除、撤销与最近删除恢复。
4. **设置**：项目管理、时长预设或计次默认计划、提示音/震动/语音提醒、外观、字体大小、备份导入导出。

## 数据与备份

- 卸载应用会删除本机数据；**卸载前先到设置 → 导出完整备份**。
- 导入：设置 → 导入与恢复 → 选择 JSON → 预览冲突 → 合并或覆盖。覆盖前会先在本机私有目录留一份安全副本，并在一个事务里替换。
- 备份含删除标记，合并旧备份不会让已删除记录复活；相同 UUID 以现有版本为准。

## 构建与测试

需要 JDK 17、Android SDK 36：

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

## 已知限制

- 锁屏/后台语音依赖前台服务与系统通知权限；通知被拒、勿扰/静音、OEM 省电或系统强制停止时不保证准点播报，返回后仍显示真实经过时长。
- 自动备份写失败、空间不足、目录授权撤销、系统重启后的服务行为仍需按真机环境验证；训练本身不受影响。
