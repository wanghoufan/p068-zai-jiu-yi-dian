## 4. 本轮发现并修复的缺陷

1. **P0 FK 崩溃（已修）**：`ProjectDao.upsert` 的 `INSERT OR REPLACE` 在项目有历史时会瞬时删父行，触发 `sessions → projects` 外键 `RESTRICT`，归档/改名含历史项目直接崩溃。改用 `@Update`，并加 Robolectric 回归 + 真机复测。
2. **结束时被计为暂停（已修）**：点“结束训练”会调用暂停，导致记录出现 `pauseCount+1`。改为结束只取快照，不改暂停计数；复测一次暂停只显示“含暂停 1 次”（`docs/qa/evidence/52-pause-count-after-fix.png`）。
3. **撤销窗口过短（已修）**：删除提示 2.7 秒消失后无入口。延长到 4.2 秒，并新增“最近删除（N）”恢复区。
4. **种子预设单位错误（已修）**：默认项目预设写成分秒混用（15/20/25 被当成秒，显示 0.3 分）。改为 900/1200/1500 秒。
5. **深色主按钮对比度（已修）**：深色主题下白字落在浅薄荷色按钮上。新增 `onAccent`，深色用深墨色文字。
6. **归档最后一个项目后可训练已归档项目（已修）**：增加“至少保留一个可用项目”守卫与“已归档不能开始训练”检查。
7. **字体偏小（用户追加需求，已实现）**：应用内字体大小 100/115/130/145%，默认 115%，即时生效并持久化，不影响系统设置。
8. **开始/每 3 分钟无反馈（用户追加需求，已实现）**：开始训练播报“开始训练”并震动；每满 3 分钟播报“已经训练 X 分钟”；达到目标播报“已达到目标，可以继续”。全部为本地 WAV + SoundPool，离线可用，设置中可单独关闭语音。真机日志 `P068Voice` 与截图 53/54 为证。

## 5. 未验证 / 已知限制

- **锁屏准点提醒**：V1.0 未实现锁屏/后台响铃；开始/每 3 分钟/达标语音也只在应用前台时可靠播放，设置页如实说明。这是能力缺口，不是已通过项。
- **自动本地备份**：未实现（计划中的非阻塞增强）；手动 JSON/CSV 已通过。
- **正式签名与上架**：当前为 DEBUG 测试签名；公开发布/商店分发需用户授权后另行处理。
- **精确 25 分钟→10 分钟场景**：以 14 秒/1 分钟等效场景验证同一结束快照代码路径，未真实等待 10 分钟。
- **跨 Android 版本矩阵**：功能验收在 Android 14 完成；Android 15 与 Android 11 仅做安装/启动验证，未做完整功能回归。
- **MIUI 安装限制（环境风险）**：该机「USB 安装」会在锁屏/重启后自动关闭，导致 `adb install` 被系统拒绝；需在开发者选项重新开启。与应用代码无关。
