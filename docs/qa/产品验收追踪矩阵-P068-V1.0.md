## 已知边界（不冒充通过）

1. **锁屏准点提醒未实现**：V1.0 仅在应用前台时提示达标（声音/震动），设置页与说明均明确“后台或锁屏不会响铃”；返回时始终显示真实经过时长。因此 AC-07 的“不诚实提示”判据为 PASS，但产品未承诺锁屏响铃。
2. **自动本地备份未实现**：属于计划中的非阻塞增强；手动 JSON/CSV 导出与恢复为硬验收，已通过。
3. **正式签名/应用商店**：当前为 DEBUG 测试签名侧载包；首次正式对外分发需用户另行授权并与签名方案一并决策。
4. **自动测试覆盖**：Room DAO 回归（项目更新/外键）已用 Robolectric 覆盖；未做跨设备/跨 Android 版本矩阵。
5. **验收样本**：图形与统计使用合成匿名数据（`test-data/qa-backup.json`），不包含任何真实个人训练记录；交付前已清空真机应用数据。
