## 3. 隔离与共享评估

- **P059 与 P068 共用本环境，PG 目前仅 P068 使用**（P059 未写入 PG，故当前不存在实际数据混存）。
- **跨 APP 隔离未证明**：同一 Auth 环境下，`owner_uid = auth.uid()` 只隔离用户，不隔离同一用户的不同应用；envId、表前缀、`project_slug`、包名均不构成可信安全边界（SOP §1）。**两机同账号验证只证明「用户之间」隔离，不构成跨应用隔离证据。**因此在以下任一情形出现前**不得宣称按应用隔离**：
  1. P059 或其他应用开始写入本环境 PG；
  2. 任一应用出现公开多人、支付/资金、实名证照、强合规或独立备份要求（SOP §1 直接禁止共用）。
- **正式上线前复评**（触发条件：P068 V1.2 准备对外发布、或环境接入第二个写 PG 的应用、或用量超过 50%）。复评结论写入本节并更新项目清单。
- 单点风险：本环境的额度耗尽、到期、错误 RLS/DDL 或管理员 Key 泄露会影响 P059 与 P068 全部功能；P068 必须保留纯本地可用路径（离线训练 + 本地 V3 备份）。
