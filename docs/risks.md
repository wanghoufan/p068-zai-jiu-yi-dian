# 风险与待验证项｜再久一点（P068）

## 1. 高影响

### R1 首次发布尚未取得用户签收
- 影响：AC-20 为 OPEN，按红线不得称首次发布完成。
- 触发：用户尚未亲身体验并确认。
- 处置：邀请用户走一次真实训练 + 备份恢复；签收后再更新矩阵与 HANDOFF。

### R2 锁屏/后台不会响铃
- 影响：用户锁屏等达标时无提醒；返回后时长与达标状态准确。
- 触发：应用不在前台。
- 处置：V1.0 已在设置页与说明中如实标注；若用户要求锁屏提醒，需另做通知权限/AlarmManager 专项（Android 版本限制需实测），不得假报成功。

### R3 当前为 DEBUG 测试签名
- 影响：不可作为正式商店分发；升级安装可能受签名限制。
- 触发：公开发布/上架。
- 处置：正式分发前与用户确认签名方案；不得擅自更换正式签名或发布。

## 2. 中影响

### R4 MIUI「USB 安装」会自动关闭
- 影响：锁屏/重启后 `adb install` 报 `INSTALL_FAILED_USER_RESTRICTED`，与 APK 无关。
- 触发：小米 HyperOS 设备锁屏或重启后。
- 处置：在开发者选项重新打开「USB 安装」后立即安装；保持屏幕常亮；记录于 QA 报告。

### R5 卸载会删除本机数据
- 影响：未导出备份时，卸载/清数据会丢失历史。
- 触发：卸载、系统清理、换机。
- 处置：设置页明示“卸载前先导出”；V1.0 不提供自动备份（计划中的非阻塞增强）。

### R6 覆盖导入的安全快照仅在本机私有目录
- 影响：覆盖导入前的安全副本写在 `files/safety-backups/`，普通用户无法直接浏览/再次导入。
- 触发：覆盖导入后想回退。
- 处置：覆盖前提示先导出；如需用户可操作的回滚，V1.1 再提供“恢复安全副本”入口。

## 3. 低影响 / 观察项

- **R7 超大字体下图表较密**：145% + 系统大字体时坐标标签更紧凑，目前不遮挡；若用户反馈可再降图表字号上限。
- **R8 仅 Android 15 真机验证**：未覆盖 Android 8–14 与不同 ROM；核心 API 均为 minSdk 26 可用，但仍属未验证范围。
- **R9 全部项目混合统计**：已加“多项目表现不宜合并推断”提示；分组表仍会展示整体关联，需持续避免因果表述。
